# BetMind AI

BetMind AI es una plataforma de inteligencia deportiva orientada a detectar apuestas con valor esperado positivo (+EV).

## Objetivo

Construir un sistema profesional que:

- Obtenga datos automáticamente.
- Los almacene en una base de datos.
- Calcule probabilidades mediante modelos estadísticos y Machine Learning.
- Detecte Value Bets.
- Explique cada recomendación mediante IA.
